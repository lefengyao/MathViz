# 立体几何

立体图的目标不是"像"，而是**能读懂空间关系**：谁在前面、谁被挡住、哪个角是哪个面之间的角。

## 一、视角怎么选

```js
MK.space({ yaw:-30, pitch:20, range:3 })
```

| 参数 | 含义 | 常用值 |
|---|---|---|
| `yaw` | 绕 z 轴旋转 | `-30`（默认，x 右下 / y 右上）、`-45`（更对称）、`20`（换一侧） |
| `pitch` | 俯视角 | `18~25`（课本常用）、`0`（平视）、`-60`（俯视，看顶面） |
| `range` | 视野半径 | 图形坐标跨度的一半再乘 1.4 |
| `zoom` | 微调 | `0.85~1.15` |

默认 `yaw=-30, pitch=20` 给出标准右手系画法：**x 轴指向右下、y 轴指向右上、z 轴竖直向上**。这符合国内教材习惯，不要随便改。

`range` 给错会导致图形太小或出框。经验公式：`range = 最大坐标绝对值 × 1.4`。

```js
// 长方体 [0,3]×[0,2]×[0,1.5]，最大坐标 3
MK.space({ range: 3*1.4, yaw:-30, pitch:20 });
```

## 二、常用立体

```js
// 长方体：两个对角点
S.box([0,0,0], [2,2,2], { color:"blue" });

// 棱柱：底面点列（逆时针）+ 高
S.prism([[0,0],[2,0],[2.4,1.6],[0.4,1.6]], 2.2, { color:"teal" });

// 棱锥：底面点列 + 顶点
S.pyramid([[0,0],[2,0],[2.6,1.6],[0.6,1.6]], [1.3,0.8,2.4], { color:"purple" });

// 圆柱 / 球
S.cylinder([0,0,-1.2], 0.9, 2.4, { color:"amber" });
S.sphere([0,0,0], 1.3, { color:"teal" });
```

### 棱台、组合体这类没有内置的

用 `S.solid(verts, faces, opt)`。关键是 **faces 里每个面从外面看逆时针**。

```js
// 四棱台：下底 2×2，上底 1×1，高 1.6
var v = [
  [0,0,0],[2,0,0],[2,2,0],[0,2,0],          // 0-3 下底
  [0.5,0.5,1.6],[1.5,0.5,1.6],[1.5,1.5,1.6],[0.5,1.5,1.6]  // 4-7 上底
];
var f = [
  [0,3,2,1],                                  // 下底（法线朝 -z）
  [4,5,6,7],                                  // 上底（朝 +z）
  [0,1,5,4],[1,2,6,5],[2,3,7,6],[3,0,4,7]     // 四个侧面
];
S.solid(v, f, { color:"blue" });
```

绕向反了会怎样：该画虚线的边画成实线，整个立体的前后关系就颠倒了。**画完一定检查最后面的那一两条棱是不是虚线。**

## 三、截面

截面就是「用一个平面去切多面体」。做法：求出平面与各条棱的交点，按顺序连成多边形。

### 平行于底面

```js
// 立方体 [0,2]³，在 z=1.2 处水平截
S.face([[0,0,1.2],[2,0,1.2],[2,2,1.2],[0,2,1.2]], { color:"coral", opacity:0.35 });
```

### 过三个已知点

三点 `P, Q, R` 确定平面。与棱 `AB` 的交点用参数式：

```js
function hitPlane(P,Q,R, A,B) {
  var n = cross(sub(Q,P), sub(R,P));
  var da = dot(n, sub(A,P)), db = dot(n, sub(B,P));
  if (Math.abs(da - db) < 1e-9) return null;      // 平行，无交点
  var t = da / (da - db);
  if (t < -1e-9 || t > 1+1e-9) return null;        // 交点在棱的延长线上
  return [A[0] + t*(B[0]-A[0]), A[1] + t*(B[1]-A[1]), A[2] + t*(B[2]-A[2])];
}
```

对 12 条棱各算一次，收集落在棱内的交点，按绕中心的角度排序，就是截面多边形。

**教学图上更省事的做法**：直接按几何直觉给出截面顶点（比如「过三条棱中点」），画出来即可。只有题目明确要求"求截面"时才需要严格计算。

## 四、二面角

二面角不是两条棱之间的角，是**两个面之间的角**。画法：

1. 在交线 `l` 上取一点 `O`；
2. 在两个面内各作一条垂直于 `l` 的射线 `OA`、`OB`；
3. `∠AOB` 就是二面角的平面角。

```js
// 交线是 z 轴，两个面是 xz 平面和 yz 平面
var O = [0,0,1];
S.angle(O, [1,0,1], [0,1,1], { r:0.6, label:"90°" });
```

直接对顶点用 `S.angle` 只会得到「两条边的夹角」，**不是二面角**。这一点最容易错。

## 五、辅助元素

| 要画 | 做法 |
|---|---|
| 高（垂直底面） | `S.line` + `S.face` 画直角标记，或 `S.angle` 标 90° |
| 投影点 | 从顶点垂直落到底面的点，用虚线连 |
| 对角线 | `S.line(a, b, {dash:true})` |
| 面内的一条线 | `S.line`，颜色区别于棱 |
| 平面 | `S.plane(origin, u, v, {opacity:0.2})` |
| 空间向量 | `S.arrow([0,0,0], [1,2,1], {color:"coral", label:"a"})` |

平面用很低的透明度（0.15~0.25），否则会盖住后面的棱。

## 六、三视图

三视图不是投影图，是三个正交方向的**正投影**。用 2D 画布分别画：

```js
// 主视图（正面）
var Vf = MK.frame({ box:[40,30,180,180], x:[-0.5,3], y:[-0.5,3], equal:true, grid:false, axes:false });
Vf.poly([[0,0],[2,0],[2,2],[0,2]], { color:"blue", opacity:0.18 });
Vf.label([1, 2.3], "主视图", { anchor:"middle", size:11 });
```

三个 `MK.frame` 横排，间距 20px，各自 `box` 宽度 200 左右。**不要用 `MK.space` 画三视图**——它会带透视感，不是正投影。

## 七、常见错误

| 现象 | 原因 | 修法 |
|---|---|---|
| 图形太小 / 出框 | `range` 不对 | `range ≈ 最大坐标 × 1.4` |
| 隐藏边画成实线 | 面绕向反了 | 检查 faces 顶点顺序，从外看逆时针 |
| 前后关系颠倒 | 面的绘制顺序错 | 用 `S.solid`，它按深度排序 |
| 二面角标成了棱夹角 | `S.angle` 直接给了两条棱 | 先作垂线，再标平面角 |
| 圆柱上下底都画实线 | 没区分可见/遮挡 | `S.cylinder` 已处理，手写时下底虚线 |
| 球画成椭圆 | 用了错误投影 | 正交投影下球的轮廓是正圆，半径 = `r × scale` |
| 平面盖住了后面的棱 | 透明度太高 | 降到 0.15~0.25 |
