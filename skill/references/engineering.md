# 机械工程图（MK.eng）

## 什么时候用

| 需求 | 用不用 |
|---|---|
| 零件图、剖视图、尺寸链、粗糙度、基准、零件序号 | ✅ |
| 轴、法兰、支座、支架这类二维轮廓加标注 | ✅ |
| 装配示意图（几个零件 + 序号 + 明细） | ✅ |
| 三视图 / 轴测图（要有立体感） | ❌ 三视图分别画三张；轴测图用 `MK.space` |
| 电路 / PCB | ❌ 用 `MK.schematic` / `MK.pcb` |

## 坐标规则

- 单位是**毫米**，**原点在左下角、y 向上**——和你脑子里的零件坐标一致，不用做翻转换算。
- 用 `ext:[宽, 高]` 声明这张图大概要画多大范围。它只是**比例提示**：
  脚本跑完后运行时会按实际画出来的内容重新贴合画幅，所以 `ext` 估得不准也不会把图挤到角落或被裁掉
  （写大一倍只是让中间过程小一点，最终仍会填满卡片；写小了会被自动扩边兜住）。
- 所有数值写**真实尺寸**：长 120mm 就写 120，不用管像素。

```js
var E = MK.eng({box:[40,26,600,390], ext:[140,96], title:'法兰盘主视图'});
document.getElementById('fig').appendChild(E.svg);
```

## 线型

```js
E.line([10,40], [130,40], {style:'center'});   // 点划线：中心线、对称线
E.poly(pts, {close:true});                     // 粗实线：可见轮廓（默认 solid）
E.poly(pts, {style:'dash'});                   // 虚线：不可见轮廓
E.poly(pts, {style:'phantom'});                // 双点划线：假想投影
E.poly(pts, {style:'thin'});                   // 细实线：尺寸线、剖面线
```

| style | 用途 |
|---|---|
| `solid` | 可见轮廓（粗） |
| `thin` | 尺寸线、引出线、剖面线 |
| `dash` | 不可见轮廓 |
| `center` | 中心线、轴线 |
| `phantom` | 假想投影、极限位置 |

## 基本图元

```js
E.line(a, b, opt)              // 线段
E.poly(pts, {close:true})      // 折线 / 闭合轮廓
E.rect(p, w, h, opt)           // 矩形，p 是左下角
E.circle(c, r, opt)            // 整圆（孔）
E.arc(c, r, a1, a2, opt)       // 圆弧，角度制、数学方向（逆时针为正，y 向上）
E.hatch(poly, {angle:45, gap:4})   // 在闭合多边形里打剖面线
E.centerMark(c, {r:8})         // 圆心十字（孔、圆弧中心）
```

## 尺寸标注（最重要的一节）

**不要用 `E.text` 手写尺寸数字。** 数字、箭头、尺寸界线、箭头长度都由 `dim` 系列生成，
手写的数字对不上线，也没有箭头。

```js
E.dimX([20,20], [120,20], {offset:10});                  // 横向，自动写 100
E.dimY([20,20], [20,76], {offset:14});                   // 纵向，自动写 56
E.dimX([32,32], [108,32], {offset:17, side:'bottom', text:'76'});  // 自定义文字
E.dimDia([70,48], [70,34], {dx:-8, dy:2, anchor:'end'}); // 直径，自动写 φ28
E.dimRad([70,48], [84,48], {dx:18, dy:-14});             // 半径，自动写 R14
E.dimAngle(v, p1, p2, {r:18});                           // 角度，自动写 30°
```

| 参数 | 含义 |
|---|---|
| `offset` | 尺寸线离被测边多远（mm，取正值） |
| `side` | `above`/`below`（横向）、`left`/`right`（纵向），决定放在零件哪一侧 |
| `text` | 覆盖自动数值，写公差用：`'100±0.1'`、`'φ24H7'` |
| `dx` / `dy` | **只有 `dimDia` / `dimRad` 有**，单位是**像素**，用来把文字从箭头上挪开 |
| `anchor` | 同上，`start` / `middle` / `end` |

### 排布规矩

1. **尺寸线放在零件外侧**，不要压在轮廓上。
2. 多个尺寸平行排列时，`offset` 依次递增 8~10mm；**小尺寸靠内、大尺寸靠外**。
3. 尺寸界线与被测要素之间留约 1mm 空隙（运行时自动留），不要手动画。
4. 直径/半径的文字容易压在圆弧上，用 `dx/dy` 往空白处挪（像素，一般 10~20）。
5. 一个尺寸只标一次；重复尺寸是错误，不是冗余。

## 工程符号

```js
E.roughness([120,70], 'Ra 3.2');        // 表面粗糙度，顶点贴在被测轮廓线上
E.datum([20,50], 'A');                  // 基准符号，三角贴在基准面上
E.sectionCut([163,80], [14,80], {label:'A'});  // 剖切符号，标 A—A
E.balloon(1, [30,32], {to:[24,28]});    // 零件序号：圆圈数字 + 引线
E.leader([50,57], [96,78], 'φ24 通孔'); // 引出标注
E.viewLabel(70, 2, '主视图');            // 视图名，文字带下划线
```

`roughness` 的符号长边朝右上、文字跟在后面；`datum` 默认三角朝上，`{down:true}` 朝下。

## 剖视图

画法固定三步：**画半边轮廓 → 打剖面线 → 画中心线**。

```js
var half = [[20,34],[20,52],[60,52],[60,62],[115,62],[115,52],[155,52],[155,34]];
E.poly(half, {close:true});
E.hatch(half, {angle:45, gap:4});
E.line([8,43],[166,43], {style:'center'});
```

- 剖面线只打在被切到的实体里——所以 `hatch` 传的多边形要和轮廓**完全一致**。
- 相邻零件的剖面线方向要相反（45° / 135°）。
- 对称件可以只画一半，用中心线收尾。

## 完整示例

### 法兰盘（轮廓 + 孔 + 尺寸 + 粗糙度）

```js
var E = MK.eng({box:[40,26,600,390], ext:[140,96], title:'法兰盘主视图'});
document.getElementById('fig').appendChild(E.svg);
var out = [[20,20],[120,20],[120,76],[20,76]];
E.poly(out, {close:true});
E.circle([70,48], 14);
[[32,32],[108,32],[32,64],[108,64]].forEach(function(c){ E.circle(c,5); E.centerMark(c,{r:8}); });
E.circle([70,48], 20.5);
E.line([6,48],[134,48], {style:'center'});
E.line([70,10],[70,86], {style:'center'});
E.dimX([20,20],[120,20], {offset:10});
E.dimY([20,20],[20,76], {offset:14});
E.dimX([32,32],[108,32], {offset:17, text:'76'});
E.dimDia([70,48],[70,34], {dx:-8, dy:2, anchor:'end'});
E.dimRad([70,48],[84,48], {dx:18, dy:-14});
E.roughness([92,76], 'Ra 3.2');
E.leader([108,64], [126,86], '4×φ10 均布');
E.viewLabel(70, 2, '主视图');
```

### 阶梯轴（剖视 + 尺寸链）

```js
var E = MK.eng({box:[40,26,600,390], ext:[170,100], title:'阶梯轴（A—A 剖视）'});
document.getElementById('fig').appendChild(E.svg);
var half = [[20,34],[20,52],[60,52],[60,62],[115,62],[115,52],[155,52],[155,34]];
E.poly(half, {close:true});
E.hatch(half, {angle:45, gap:4});
E.line([8,43],[166,43], {style:'center'});
E.dimX([20,34],[60,34], {offset:12, text:'40'});
E.dimX([60,34],[115,34], {offset:12, text:'55'});
E.dimX([115,34],[155,34], {offset:12, text:'40'});
E.dimY([20,34],[20,52], {offset:14});
E.dimY([60,52],[60,62], {offset:20});
E.sectionCut([163,80],[14,80], {label:'A'});
E.viewLabel(85, 92, 'A—A');
E.roughness([155,52], 'Ra 1.6');
```

## 反模式

1. **`E.text([70,10], '100')` 手写尺寸** —— 没有箭头、没有尺寸界线，还容易和别的线撞。
2. **y 轴当向下用** —— `E.dimY` 会标到别的边上。记住 y 向上，零件顶部是**大数值**。
3. **`offset` 写负数想换边** —— `offset` 取绝对值，换边要用 `side`。
4. **`dimDia` 的 `dx/dy` 里写毫米** —— 这两个是像素，写 8 就是挪 8px，不是 8mm。
5. **剖面线多边形和轮廓不一致** —— 会打到轮廓外面。
6. **尺寸线穿过零件** —— 小尺寸在内、大尺寸在外，`offset` 逐个加大。
7. **一张图塞十个尺寸** —— 只标必要的定位与配合尺寸，其余进技术要求。
