# 向量与线性代数

## 一、向量

```js
var V = MK.frame({ box:[40,26,600,330], x:[-3,3], y:[-2,4], equal:true, axes:true, grid:true });
V.arrow([0,0], [2,1], { color:"blue", label:"v" });
V.dot([2,1], { color:"blue", label:"", r:3 });
```

- 向量**从原点出发**是默认约定；自由向量才从别处起。
- 标签放在箭头中点的侧上方，不要压在箭头上（`label` 已自动偏移，方向不合适时用 `V.label` 手动放）。
- 分量写法 `v = (2, 1)` 用正体数字 + 斜体字母。

### 加法（平行四边形法则）

```js
var a = [2,0.6], b = [0.8,1.8];
V.arrow([0,0], a, { color:"blue",  label:"a" });
V.arrow([0,0], b, { color:"coral", label:"b" });
V.seg(a, [a[0]+b[0], a[1]+b[1]], { dash:true, color:"blue" });   // 平移 a
V.seg(b, [a[0]+b[0], a[1]+b[1]], { dash:true, color:"coral" });  // 平移 b
V.arrow([0,0], [a[0]+b[0], a[1]+b[1]], { color:"purple", label:"a + b", w:2 });
```

虚线是"平移过来的边"，画出来才有平行四边形法则的直观。**不画虚线就只是两条斜线，读者看不出和向量等于什么。**

### 减法

`a − b` 从 `b` 的终点指向 `a` 的终点。画的时候把 `a` 和 `b` 都从原点起，再加一条 `b → a` 的箭头。

## 二、坐标分解与投影

```js
var v = [2.4, 1.6];
V.arrow([0,0], v, { color:"blue", label:"v" });
V.seg([0,0], [v[0],0], { color:"coral", w:2 });      // x 分量
V.seg([v[0],0], v,     { color:"teal",  w:2 });      // y 分量
V.seg([v[0],0], [v[0], v[1]], { dash:true, color:"gray" });
V.rightAngle([v[0],0], [0,0], v);
```

投影到任意方向 `u`：

```js
// proj_u v = (v·u / u·u) u
var d = (v[0]*u[0] + v[1]*u[1]) / (u[0]*u[0] + u[1]*u[1]);
var p = [u[0]*d, u[1]*d];
V.arrow([0,0], p, { color:"green", label:"proj" });
V.seg(v, p, { dash:true, color:"gray" });   // 垂线，要画直角
V.rightAngle(p, v, [0,0]);
```

垂线**必须画直角标记**，否则看不出是投影而不是随便一条线。

## 三、线性组合与张成空间

```js
var a = [1.6,0.4], b = [0.2,1.4];
V.arrow([0,0], a, { color:"blue",  label:"a" });
V.arrow([0,0], b, { color:"coral", label:"b" });

// 用梳状网格表示 span{a,b}：系数在 [-2,2] 内的所有组合
for (var i = -2; i <= 2; i++) {
  for (var j = -2; j <= 2; j++) {
    if (i === 0 && j === 0) continue;
    V.dot([a[0]*i + b[0]*j, a[1]*i + b[1]*j], { r:2, color:"gray" });
  }
}
```

要点：

- **两个不共线向量的 span 是整个平面**，图中用网格点示意"可以取到任何一点"。
- **共线时 span 是一条直线**，这时画一条穿过原点的直线 + 几个取到的点。
- 三个向量在 2D 里必然线性相关：其中一个可以写成另外两个的组合。图里画三个箭头并标注 `c = a + b`。

## 四、线性变换

线性变换由矩阵决定。可视化的关键：**看基向量去哪了**。

```js
// 矩阵 [[1,1],[0,1]]（剪切）
var M = function(p){ return [p[0] + p[1], p[1]]; };

// 变换前的网格
for (var t = -3; t <= 3; t += 1) {
  V.seg([t,-2], [t,4], { color:"gray", w:0.8, opacity:0.35 });
  V.seg([-3,t], [3,t], { color:"gray", w:0.8, opacity:0.35 });
}
// 变换后的网格（平行线族，线数一致）
for (var t2 = -3; t2 <= 3; t2 += 1) {
  V.param(s => M([t2, s]), { t0:-2, t1:4, color:"blue", w:1 });
  V.param(s => M([s, t2]), { t0:-3, t1:3, color:"blue", w:1 });
}
```

- 变换前后用**同一套颜色**，靠透明度区分（前 0.35，后 1）。
- 单位正方形 `[0,1]²` 的像用半透明填充，面积就是 `|det M|`。
- 箭头标出 `e₁ → Me₁`、`e₂ → Me₂`，比画一堆网格线更直观。

### 行列式

`det = 0` 时，整个平面被压成一条直线——这一点必须画出来（网格退化成平行线族，正方形变成一个点或线段）。

```js
// 退化变换 [[1,2],[0.5,1]]，det = 0
```

## 五、特征向量

特征向量 = 变换后**方向不变**的向量（只伸缩）。

```js
// 矩阵 [[2,1],[1,2]]，特征值 3 和 1
// 特征向量 (1,1) 和 (1,-1)
V.seg([-2,-2],[2,2],   { dash:true, color:"coral" });   // 特征方向 1
V.seg([-2,2], [2,-2],  { dash:true, color:"teal"  });   // 特征方向 2
V.arrow([0,0], [1,1],  { color:"coral", label:"v₁" });
V.arrow([0,0], [3,3],  { color:"coral", label:"Av₁ = 3v₁", w:2 });
V.arrow([0,0], [1,-1], { color:"teal",  label:"v₂" });
V.arrow([0,0], [1,-1], { color:"teal",  label:"Av₂ = 1·v₂" });
```

`Av₂ = v₂` 时箭头重合，标注写 `Av₂ = v₂` 并在图里加个小注释说明"长度不变"。**重合的箭头看不出来**，这是特征值 1 特有的问题。

## 六、点积与夹角

```js
V.angle([0,0], a, b, { r:34, label:"θ" });
// cos θ = (a·b) / (|a||b|)
```

钝角（点积为负）时弧要画在大的一侧，`V.angle` 取的是小弧，钝角会显示成锐角——**这是 `V.angle` 的已知行为**。钝角请手动算角度值，或把两个向量分别反向后再标。

## 七、常见错误

| 现象 | 原因 | 修法 |
|---|---|---|
| 平行四边形法则看不出关系 | 没画平移虚线 | 补 `dash:true` 的边 |
| 投影不是垂直的 | 没画直角标记 | `V.rightAngle` |
| 变换前后网格线数不一致 | 两条循环范围不同 | 前后用同一个 `t` 范围 |
| 特征向量看起来仍在转 | 箭头太短，看不出方向 | 箭头给到 2~3 倍单位长 |
| 夹角标成了钝角里的锐角 | `V.angle` 只取小弧 | 手算角度并直接用 `V.label` |
| 向量标签压在箭头上 | 默认偏移方向不合适 | `V.label` 手动指定偏移 |
