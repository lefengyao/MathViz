# PCB 布局（MK.pcb）

## 什么时候用

| 需求 | 用不用 |
|---|---|
| 板框 + 封装摆放 + 走线 / 过孔 / 丝印 | ✅ |
| 插件 / 贴片元件在板上的相对位置、布线示意 | ✅ |
| 元件之间的电气连接（不看物理位置） | ❌ 用 `MK.schematic` |
| 多层叠层、阻抗、EMC 分析 | ❌ 这不是仿真器，只画示意 |

## 坐标规则

- 单位是**毫米**，原点在板框**左上角**，**y 向下**（和屏幕一致，不是数学习惯）。
- 所有距离、孔径、线宽都按真实毫米写，不用管像素。运行时会自动缩放并居中。
- 板子尺寸由 `board:[宽, 高]` 给定；`box` 只决定这张图占多大区域。

```js
var P = MK.pcb({box:[40,24,600,380], board:[50,32], title:'降压模块 PCB'});
document.getElementById('fig').appendChild(P.svg);
```

## 画法顺序

固定按这个顺序，否则层序会乱：**板框 → 网格（可选）→ 封装 → 走线/过孔 → 丝印 → 尺寸 → 图例**。

### 1. 板框

```js
P.outline({r:2});          // 圆角 2mm；默认在板下方标「50 × 32 mm」
```

### 2. 封装

```js
P.footprint('0805', {at:[12,9], ref:'R1', value:'10k'});
P.footprint('sot23', {at:[24,10], ref:'Q1', value:'AO3400', rot:180});
P.footprint('soic8', {at:[36,16], ref:'U1', value:'LM358'});
P.footprint('dip8',  {at:[20,24], ref:'U2', value:'NE555'});
P.footprint('header',{at:[8,25], n:3, ref:'J1', value:'IN'});
```

| 封装 | 参数 | 用途 |
|---|---|---|
| `0603` `0805` `1206` `1210` | `at` `rot` | 电阻、电容、电感 |
| `sot23` | `at` | 小功率管、LDO |
| `soic8` | `at` `pins`(默认 8) `pitch`(1.27) `row`(1.75) | 贴片 IC |
| `dip8` | `at` `pins` `pitch`(2.54) `row`(3.5) | 直插 IC |
| `header` | `at` `n` `rot` | 排针、接线端子 |

`ref`（位号）和 `value`（参数）由封装自动标在元件上下方，**不要再手动 `P.silk` 写一遍**。

### 3. 走线

```js
P.route([25,10], [36,14], {w:0.6});                        // 自动 45° 折线（优先）
P.trace([[12,9.95],[18,9.95],[18,10],[22.8,10]], {w:0.5}); // 指定拐点
P.trace([[12,16.05],[20,16.05],[20,18],[36,18]], {w:0.5, layer:'bottom'});
```

- `route` 走「横 → 45° → 横」，是真实布线最常用的形状；**能用 route 就别用 trace**。
- `trace` 的顶点必须落在焊盘中心或焊盘边缘，否则线头悬空。
- 默认线宽 0.35mm；电源线 0.6~1.0mm，信号线 0.25~0.4mm。
- 换层用 `P.via([x,y], {pad:0.9, drill:0.4})`：顶层红、底层蓝，颜色自动区分。
- 走线不能穿过别的封装的焊盘，也不能出板框（一般离板边留 0.5mm 以上）。

### 4. 焊盘与丝印

```js
P.pad([44,26], {w:3.2, h:3.2, shape:'circle', drill:1.4});  // 安装孔 / 大焊盘
P.silk('GND', [40.5,29.5]);                                  // 丝印文字
P.silk([5,5],[10,5], {dash:true});                           // 丝印线
```

### 5. 尺寸与图例

```js
P.dim([0,0],[50,0], {offset:9});      // 横向尺寸，默认放在板上方 9mm
P.dim([50,0],[50,32], {offset:9});    // 纵向尺寸，默认放在板右侧
P.legend([{color:'top',text:'顶层铜箔'},{color:'bottom',text:'底层铜箔'},
          {color:'pad',text:'焊盘 / 过孔'},{color:'silk',text:'丝印'}]);
```

`dim` 的 `side` 可选 `above/below`（横向）或 `left/right`（纵向），默认朝板外。

## 布局习惯

1. **先定板框再放封装**：封装坐标要在 `0..宽` × `0..高` 之内，并且离板边留 1mm 以上。
2. 同类元件**对齐同一行或同一列**，位号才不会互相压。
3. 大件（IC、连接器）先放，小件（阻容）围在它周围。
4. 同一网络的走线尽量走直线，少拐弯；必须拐弯时用 45°，不要 90° 直角。
5. 两个元件之间至少留 2mm，否则丝印框会叠在一起。
6. 图例固定在左下角，别和板框、尺寸线抢位置。

## 完整示例

```js
var P = MK.pcb({box:[40,24,600,390], board:[50,32], title:'降压模块 PCB（顶层视角）'});
document.getElementById('fig').appendChild(P.svg);
P.outline({r:2});
P.grid({step:5});
P.footprint('0805', {at:[12,9], ref:'R1', value:'10k'});
P.footprint('0805', {at:[12,17], ref:'R2', value:'1k'});
P.footprint('sot23', {at:[24,10], ref:'Q1', value:'AO3400'});
P.footprint('soic8', {at:[36,16], ref:'U1', value:'LM358'});
P.footprint('header', {at:[8,25], n:3, ref:'J1', value:'IN'});
P.trace([[12,9.95],[18,9.95],[18,10],[22.8,10]], {w:0.5});
P.route([25,10],[36,14], {w:0.6});
P.trace([[12,16.05],[20,16.05],[20,18],[36,18]], {w:0.5, layer:'bottom'});
P.via([20,20], {pad:0.9, drill:0.4});
P.pad([44,26], {w:3.2, h:3.2, shape:'circle', drill:1.4});
P.silk('GND', [40.5,29.5]);
P.dim([0,0],[50,0], {offset:9});
P.dim([50,0],[50,32], {offset:9});
P.legend();
```

## 反模式

1. **坐标用像素** —— 传 `[380, 240]` 想放到板中间，结果跑到板外。用毫米：`[25, 16]`。
2. **y 轴当向上用** —— PCB 的 y 向下，`at:[10,5]` 在板上部，`at:[10,27]` 在下部。
3. **忘了 `P.outline`** —— 只剩一堆焊盘浮在白底上。
4. **走线穿过焊盘** —— 视觉上像短路。绕开焊盘，或从底层走。
5. **手动重复标位号** —— 封装已经标了 `ref` / `value`，再 `P.silk('R1', ...)` 会出现两个 R1。
6. **`trace` 只给两个点又想要 45°** —— 两点连成斜线不是 45° 布线，用 `route`。
