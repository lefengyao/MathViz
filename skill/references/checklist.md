# 出图自检

## 一、十条必查

出图前逐条过，任何一条不过就改。

- [ ] **1. 坐标系方向对**：数学 y 向上。函数图没有上下颠倒。
- [ ] **2. 比例对**：几何图 `equal:true`，圆是圆的，直角看起来是直角。
- [ ] **3. 断点对**：`tan`、`1/x`、阶跃函数没有假的竖直连线。
- [ ] **4. 标注齐**：题目要求的点、角、长度、权重都标了；没要求的一个没多标。
- [ ] **5. 文字不出框**：所有标签在 x=40~640、y ≤ H−20 内，中文没被裁。
- [ ] **6. 显式 fill**：每个 `path/rect/circle` 都写了 `fill` 或 `fill="none"`。
- [ ] **7. 字号合规**：没有 < 11px 的字；字重只有 400 / 500。
- [ ] **8. 图例不挡图**：图例放在空白处，没压住曲线或节点。
- [ ] **9. 立体隐藏边**：该虚线的棱是虚线，且位置在立体"后面"。
- [ ] **10. 一张图一件事**：没有把整个证明塞进一张图。

批量检查：

```bash
node scripts/verify.mjs 页面.html
```

输出越界元素和字号过小的文字。**越界必须修，不能靠"看起来还行"放过。**

## 二、现象 → 成因

### 坐标系与曲线

| 现象 | 成因 | 修法 |
|---|---|---|
| 函数图上下颠倒 | 没翻转 y 轴 | 用 `V.plot`，或 `py = y0 + h - (y-ymin)*sy` |
| 曲线变折线 | 采样点太少 | `n` 提到 600+ |
| 渐近线处一条竖线 | 没做断点 | 像素跳变检测，或调小 `jump` |
| 曲线贴边被切 | 值域太窄 | 放大 `y` 范围 |
| 圆变椭圆 | `equal:false` | 改 `true` |
| 角度标注位置怪 | 顶点顺序反了 | 弧走的是小弧，确认三点位置 |

### 3D

| 现象 | 成因 | 修法 |
|---|---|---|
| 图形太小/出框 | `range` 估算错 | `range ≈ 最大坐标 × 1.4` |
| 隐藏边画成实线 | 面绕向反了 | 从外看逆时针重排 |
| 前后颠倒 | 面没按深度排序 | 用 `S.solid` |
| 二面角标成棱夹角 | 直接对两条棱取角 | 先作交线垂线 |
| 球变椭圆 | 用错投影 | 正交投影下轮廓是正圆 |

### 图论

| 现象 | 成因 | 修法 |
|---|---|---|
| 边穿过节点 | 手写坐标 | 用 `MK.graph`（自动避让） |
| 哈斯图多边 | 画了传递边 | 只留覆盖关系 |
| 树层级乱 | 用了 `force` | 改 `tree` |
| 箭头消失 | 没定义 marker | 用手绘三角（mathkit 已如此） |
| 多重边重叠 | 没区分序号 | 运行时自动弯，手写要加偏移 |

### 排版

| 现象 | 成因 | 修法 |
|---|---|---|
| 中文被裁 | 按英文字宽估算 | 中文按 1em/字算 |
| 文字与线重叠 | 没加描边 | `paint-order:stroke` + 背景色描边 |
| 标签跑到画布外 | 没检查边界 | 跑 `verify.mjs` |
| 图例挡曲线 | 位置随手放 | 先看曲线走向再定位置 |

## 三、数学符号

直接用 Unicode，不要用 `<tspan>` 拼上下标（渲染不稳、宽度难算）。

```
希腊字母   α β γ δ θ λ μ σ φ ω Δ Σ Π Ω
运算       + − × ÷ ± ∓ · √ ∛ ∑ ∏ ∫ ∬ ∂ ∇
关系       = ≠ ≈ ≡ < > ≤ ≥ ≪ ≫ ∝ ∼
集合       ∈ ∉ ⊂ ⊃ ⊆ ⊇ ∪ ∩ ∅ ∁ ℘
逻辑       ¬ ∧ ∨ ∀ ∃ → ↔ ⇒ ⇔ ∴ ∵
几何       ∠ ⊥ ∥ △ □ ○ ∽ ≌ ⌒ ° ′ ″
箭头       → ← ↑ ↓ ⇒ ⇐ ⇔ ↦ ⟶
其他       ∞ ℵ ℝ ℕ ℤ ℚ ℂ ⊕ ⊗ ⊙ ∣ ∤
下标       x₀ x₁ x₂ xₙ aᵢ aⱼ
上标       x² x³ xⁿ x⁻¹ f′ f″
```

组合箭头（`v⃗`）在部分字体下会偏移，**不要用**。向量用斜体加粗或直接写 `v`。

## 四、排版惯例

| 元素 | 写法 |
|---|---|
| 变量、函数名、点 | 斜体 serif：`x`, `f(x)`, `A` |
| 数字、运算符、单位 | 正体 sans |
| 向量名 | 斜体：`v`，分量写 `v = (2, 1)` |
| 角度 | 希腊字母 `α θ φ`，或数字 `30°` |
| 坐标点 | `A(1, 2)`，括号用全角或半角都行，同一张图内统一 |
| 函数式 | `y = x² − 2`，减号用 `−`（U+2212）不是 `-` |

字号阶梯：**13px 正文标注 / 12px 点与刻度 / 11px 最小值（图例、次级标注）**。
不要在同一张图里出现 5 种字号。

## 五、配色语义

一套图里颜色要有固定含义，不要随机分配。

| 用途 | 色 |
|---|---|
| 主对象（第一条曲线、主向量） | `blue` |
| 对比对象（第二条曲线） | `coral` |
| 辅助线、原始位置 | `gray` + 虚线 |
| 变换后、目标状态 | `teal` |
| 强调、答案、最优路径 | `red` |
| 填充区域 | 对应色的 `50` 档，透明度 0.3~0.5 |

同类型的多个对象（比如三个面）用同一色系的不同深浅，不要用三种撞色。

亮色主题：浅填充 + 深描边 + 更深文字。暗色主题反过来。
**每次取色都调 `widget_guidelines` 拿当次调色板**，不要凭记忆写 hex。

## 六、尺寸

- `viewBox="0 0 680 H"`，`680` 不可改。
- 内容安全区 `x = 40 ~ 640`。
- `H` = 最底部元素的底边 + 20，不要猜。
- 单张图高度建议 280~420。超过 480 就该拆成两张。
- 横向元素超过 4 个（并列的节点、并列的图例项）考虑改成纵向排列。
