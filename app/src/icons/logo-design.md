# MathViz Logo 设计规范

> 状态：已定稿。**最终版 = V3 坐标纸变体 + 坐标轴**：深蓝底 #185FA5 + 16% 白网格（间距 64，线宽 3）+ 白轴（线宽 12，y 轴 x=128 / x 轴 y=384，与网格线重合）+ 白色正弦（宽 24，波峰 197,208 / 波谷 388,445）+ 珊瑚峰值点 #D85A30 r=26。16/32 加粗变体：轴 20 / 波 40 / 点 r34。母版 `src/icons/logo.svg`，导出脚本 `test/export-logo.mjs`。

## 1. 品牌定位

- **产品**：MathViz for DeepSeek —— 在对话里把 `mathviz` 代码块渲染成数学图形
- **关键词**：数学、即时可视化、轻量、准确、亲切
- **气质**：像一个漂亮的黑板/练习本角落里的示意图，不是冷冰冰的工程图标

## 2. 概念

**「一画即成」**：一条正弦曲线是数学最经典的视觉符号，坐标轴 + 曲线 + 峰值点 = 一次最小完整的「作图行为」。
三个元素分别对应产品的三层能力：

| 元素 | 含义 |
|---|---|
| 坐标轴 | 运行时（MK.frame 的网格与刻度） |
| 正弦曲线 | 曲线/函数渲染能力 |
| 峰值点 | 标注与交互（dot/label/onPick） |

不采用：立方体（3D 只是能力之一，不够普适）、围栏符号（代码感过重，挤压数学感）。

## 3. 几何规格（512 网格）

```
画布        512 × 512，圆角 112（≈ squircle 视觉）
x 轴        (80,432) → (432,432)，线宽 10，圆头
y 轴        (112,462) → (112,70)，线宽 10，圆头
曲线        M96,330 C158,168 236,168 298,330
            C360,492 424,474 458,336
            线宽 20，圆头；波峰 (197,208)、波谷 (388,445)，
            波谷穿轴下探 13px —— 打破完全对称，增加手绘感
峰值点      (197,208) r=20，落在波峰最高处
轴端        不加箭头（16px 下箭头糊成团）
```

留白：曲线最左点 x=96 距左边 96px（18.75%），四个方向呼吸感均衡。

## 4. 色彩

| 角色 | 浅色主题（默认） | 说明 |
|---|---|---|
| 底 | `#185FA5` c-blue-600 | 沉稳、和运行时 blue 主色同族 |
| 轴 / 点 | `#FBFAF7` 纸白 | 与渲染画布底色同源，不是纯白 |
| 曲线 | `#F0997B` c-coral-400 | 与 blue 的经典互补对，即渲染里 `coral` |

**深色主题变体**（暂不启用，规范先存）：底 `#042C53`（c-blue-900），轴/点 `#B5D4F4`（c-blue-200），曲线 `#F0997B` 不变。
禁：纯黑 `#000`、纯白 `#FFF`（太硬）；渐变（违背产品 flat 风格）。

## 5. 尺寸适配体系

| 尺寸 | 变体 | 处理 |
|---|---|---|
| 16 / 32（工具栏） | 加粗版 | 轴 10→18，曲线 20→34，点 r20→28；细节让位于轮廓 |
| 48 / 128（管理页/商店） | 标准版 | 按第 3 节原样 |
| Android 普通图标 | 标准版 | 48/72/96/144/192 五密度 |
| Android 自适应前景 | 前景版 | 去底色，图形组缩放 0.62 居中（108dp 安全区 66dp），背景纯色 `#2C2C2A`？ |

> ⚠️ 待确认项 ①：Android 自适应背景色。现状是沿用旧方案 C 的墨色 `#2C2C2A`，
> 与前景不配套。建议改为 `#185FA5`（与浅色主题底一致），桌面观感统一；
> 或保持墨色形成「桌面深、打开浅」的对比。**默认按 `#185FA5` 改。**

## 6. 使用禁例

1. 不拉伸/不非等比缩放；最小可用尺寸 16px，低于此不渲染
2. 圆角底色只允许第 4 节色板内的值，不透明渐变、不加投影
3. 曲线与轴的相对位置（波峰点在轴左上象限）是识别特征，不得重排
4. 深色 UI 上直接放 PNG 时使用原圆角底版，不做去底（去底版仅 Android 前景用）

## 7. 交付链路（已自动化）

```
改 src/icons/logo.svg
  → node test/export-logo.mjs   （16/32 加粗、48/128 标准、Android 全套）
  → npm run build               （扩展 dist）
  → android: node build.mjs + gradlew assembleDebug
```

## 8. 待确认项

1. Android 自适应图标背景色：`#185FA5`（推荐，统一）还是维持 `#2C2C2A`（墨色对比）？
2. 曲线颜色是否够「珊瑚」？备选更亮的 `#F5C4B3`（c-coral-200，深底上更柔和）或更深的 `#D85A30`（c-coral-600，对比更强）。
3. 峰值点是否保留？（它代表交互/标注能力，去掉会更极简）
